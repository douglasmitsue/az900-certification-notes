## About

This repository contains my complete study notes for the **Microsoft Azure Fundamentals (AZ-900)** certification.

The goal of this project is to:

- 📚 Document my learning journey
- ☁️ Build a structured Azure knowledge base
- 🧪 Share practical examples and labs
- 🎯 Help other IT professionals prepare for the AZ-900 exam
- 💼 Showcase technical knowledge for recruiters and hiring managers

This repository is continuously updated as I progress through my studies.
