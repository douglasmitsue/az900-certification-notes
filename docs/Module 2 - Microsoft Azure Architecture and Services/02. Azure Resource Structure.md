
# Azure Resources

Azure resources are cloud components, such as storage, virtual machines, and networking services, that are used to build and deploy cloud solutions.

- Virtual Machines
- Storage Accounts
- Virtual Networks
- App Services
- SQL Databases
- Azure Functions

#### 1. Azure Subscriptions

- An Azure subscription provides authenticated and authorized access to Microsoft Azure services.
- **Billing boundary:** Generate separate invoices and billing reports for each subscription.
- **Access control boundary:** Manage and control access to the resources provisioned within a specific subscription.

**Example:**

Azure Account

- Development Subscription
- Testing Subscription
- Production Subscription

#### 2. Resource Groups

- A Resource Group is a logical container used to organize and manage Azure resources as a single unit.
- A resource can belong to only one Resource Group.
- Resources within the same Resource Group can reside in different Azure regions.
- Resources can be moved between Resource Groups.
- Applications can span multiple Resource Groups.

**Example:**

A web application consisting of a **Web App**, **SQL Database**, **Virtual Machine**, and **Storage Account** may be organized as:

- Web and Database Resource Group
- Virtual Machine Resource Group

#### 3. Management Groups

- Management Groups can contain multiple Azure subscriptions.
- Subscriptions inherit policies and access controls applied to the Management Group.
- A single Azure Active Directory tenant can support up to **10,000 Management Groups**.
- A Management Group hierarchy can have up to **six levels of depth**.
