
# Azure Virtual Desktop (AVD)

-  Azure Virtual Desktop is a desktop and application virtualization service that runs in the cloud.
-  Create a complete desktop virtualization environment without needing to run additional gateway servers.
-  Reduce the risk of resources being left behind.
-  Multi-session deployments.

# Azure Container Services

Azure containers provide a lightweight, virtualized environment that does not require operating system management and can respond to changes on demand.

-  **Azure Container Instances:** A PaaS offering that runs a container or a pod of containers in Azure.
-  **Azure Container Apps:** A PaaS offering—similar to Container Instances—that supports load balancing and scaling.
-  **Azure Kubernetes Service (AKS):** An orchestration service for containers featuring distributed architectures and handling large volumes of containers.

# Azure Functions

Azure Functions is a serverless compute service designed to execute small blocks of code in response to specific events, without the need to configure or manage infrastructure.

It allows you to focus solely on developing business logic, while Azure automatically handles scaling and infrastructure.

# Azure App Service

-  Azure App Service is a fully managed platform for quickly building, deploying, and scaling web applications and APIs.
-  Supports .NET, .NET Core, Node.js, Java, Python, or PHP.
-  A PaaS offering that meets enterprise-grade requirements for performance, security, and compliance.
