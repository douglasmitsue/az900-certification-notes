# 06. Azure Storage Services

# Storage Account

- A globally unique name is required.
    
- Provide worldwide access over the internet.
    
- Configure storage services and redundancy options.
    

# Azure Storage

**Azure Blob Storage:** Optimized for storing massive amounts of unstructured data, such as text or binary data.

**Azure Queue Storage:** A message storage service that provides storage and retrieval for large numbers of messages, each up to 64 KB in size.

**Azure Files:** Provides highly available network file shares that can be accessed using the Server Message Block (SMB) protocol.

**Azure Table Storage:** Provides a key/attribute store for structured, non-relational data with a schema-less design.

**Azure Disk Storage:** Provides disks that virtual machines, applications, and other services can access and use.

# Storage Account Public Endpoints

#### Storage Service / Public Endpoint

Blob Storage: `https://<storage-account-name>.blob.core.windows.net`  
Data Lake Storage Gen2: `https://<storage-account-name>.dfs.core.windows.net`  
Azure Files: `https://<storage-account-name>.file.core.windows.net`  
Queue Storage: `https://<storage-account-name>.queue.core.windows.net`  
Table Storage: `https://<storage-account-name>.table.core.windows.net`

# Azure Storage Access Tiers

#### Blob-Level Tiers

**Hot tier:** Optimized for frequently accessed objects in the storage account.

**Cool tier:** An online tier optimized for data that is accessed or modified infrequently. Data in the Cool tier should be stored for a minimum of 30 days. It has lower storage costs and higher access costs compared to the Hot tier.

**Cold tier:** An online tier optimized for data that is accessed or modified infrequently. Data in the Cold tier should be stored for a minimum of 90 days. It has lower storage costs and higher access costs than the Cool tier, but lower retrieval latency than the Archive tier.

**Archive tier:** Optimized for data that can tolerate several hours of retrieval latency and will remain in the Archive tier for at least 180 days.

#### Storage Account-Level Tiers

**Hot tier:** Optimized for frequently accessed objects in the storage account.

**Cool tier:** Optimized for storing large amounts of data that are accessed infrequently and retained for at least 30 days.
