
# Azure Compute Services

Azure Compute is an on-demand service that provides computing resources such as storage disks, processors, memory, networking, and operating systems.

- Azure Virtual Machines
- Azure App Service
- Azure Container Instances
- Azure Kubernetes Service (AKS)
- Azure Virtual Desktop (AVD)

# Azure Virtual Machines (VMs) - IaaS

- Azure Virtual Machines (VMs) are one of the compute resource types offered by Azure. A VM is typically the preferred choice when you need greater control over the computing environment than other Azure compute services provide.
- An Azure VM offers the flexibility to scale and upgrade without purchasing or maintaining the underlying physical hardware. However, you are still responsible for managing the virtual machine, including configuration, patching, updates, and software installation.

# Virtual Machine Scale Sets (VMSS)

- Virtual Machine Scale Sets (VMSS) provide automatic scaling and integrated load balancing for virtual machines.
- Scale out horizontally by adding VM instances when demand increases.
- Scale in horizontally by removing VM instances when demand decreases.

# Availability Sets

- An Availability Set is a logical grouping of virtual machines that enables Azure to understand how your application is deployed in order to provide redundancy and high availability. Microsoft recommends deploying two or more VMs within an Availability Set to achieve a highly available application and qualify for the **99.95% Azure SLA**.
- There is no additional charge for an Availability Set itself; you only pay for the virtual machines you deploy.
- Each virtual machine within an Availability Set is assigned an **Update Domain (UD)** and a **Fault Domain (FD)** by the Azure platform. Additional VMs are automatically distributed across different Update Domains and Fault Domains.

# Update Domains and Fault Domains

- **Update Domains (UD):** Planned maintenance, security patches, and platform updates are applied sequentially across Update Domains, reducing application downtime.
- **Fault Domains (FD):** Provide physical separation of workloads across different hardware racks within the same data center, protecting against hardware failures.

> **Note:** An Availability Set protects against failures within a single data center. It does **not** provide protection against the outage of an entire data center.

# Availability Zones

- An Availability Zone is a physically separate location within an Azure region.
- Each Azure region that supports Availability Zones provides **at least three Availability Zones**.

**Availability Zone = Data Center (DC)**

# High Availability Options

- Single Virtual Machine with **Standard SSD**: **99.5% SLA**
- Single Virtual Machine with **Standard HDD**: **95% SLA**
