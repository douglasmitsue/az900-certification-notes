
# 01. Cloud Concepts

### -> Applies to all cloud providers

#### What is cloud computing?

It is the delivery of computing services over the internet, enabling faster innovation, flexible resources, and economies of scale.

#### What is Azure?

Microsoft Azure is a platform designed to run applications and services, based on Microsoft's cloud computing concepts.

Microsoft Azure is an open and flexible cloud solution. With Azure, we can build applications using any programming language, tool, or framework, while integrating them with applications running in the public cloud as well as with the existing IT environment.
