
# 02. Cloud Types

#### Private Cloud

Organizations create a cloud environment within their own datacenter.

- The organization is responsible for operating the services it provides.
- It does not provide access to users outside the organization.

- Hardware must be purchased for deployment and maintenance.
- Organizations have full control over resources and security.
- Organizations are responsible for hardware maintenance and updates.

#### Public Cloud

- Owned by a cloud service provider or hosting provider.
- Provides resources and services to multiple organizations and users.
- Accessed through a secure network connection (usually over the internet).

- No capital expenditure is required to scale vertically.
- Applications can be provisioned and deprovisioned quickly.
- Organizations pay only for what they use.

#### Hybrid Cloud

- Combines public and private clouds, allowing applications to run in the most appropriate location.

- Provides the greatest flexibility.
- Organizations determine where to run their applications.
- Organizations control security, compliance, and legal requirements.
