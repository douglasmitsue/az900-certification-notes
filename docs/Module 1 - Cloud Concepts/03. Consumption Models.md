
# 03. Consumption Models

#### CapEx and OpEx

#### CapEx (Capital Expenditure)

- Initial investment in physical infrastructure.
- CapEx costs have a value that depreciates over time.

#### OpEx (Operating Expenditure)

- Spending on products and services as needed, with a pay-as-you-go model.
- Billing is received immediately.

**Important:** It is possible to have both CapEx and OpEx in the cloud. In practice, approximately 99% of cloud scenarios are OpEx, while around 1% are CapEx.

**Example:** Azure Stack HCI → CapEx

https://docs.azure.cn/en-us/azure-local/overview

#### Consumption-Based Model

- Cloud service providers operate on a consumption-based model, meaning end users pay only for the resources they use. Billing is based on actual resource consumption.
- Better cost forecasting.
- Pricing is provided for individual services and resources.
- Billing is based on actual usage.

**Important:** The Azure Pricing Calculator provides only a cost estimate.
