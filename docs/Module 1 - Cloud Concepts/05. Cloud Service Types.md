
# 05. Cloud Service Types

#### IaaS (Infrastructure as a Service)

- Create a pay-as-you-go IT infrastructure by renting servers, virtual machines, storage, networking, and operating systems from a cloud provider.

#### PaaS (Platform as a Service)

- Provides an environment for building, testing, and deploying software applications without requiring you to manage the underlying infrastructure.

#### SaaS (Software as a Service)

- Users connect to and use cloud-based applications over the internet, such as Microsoft 365, email, and calendar services.

#### Cloud Service Comparison

**IaaS:**
- The most flexible cloud service model.
- You configure and manage the infrastructure required for your applications.

**PaaS:**
- Focused on application development.
- The cloud provider manages the underlying platform.

**SaaS:**
- Pay-as-you-go pricing model.
- Users pay for the software they use through a subscription model.
